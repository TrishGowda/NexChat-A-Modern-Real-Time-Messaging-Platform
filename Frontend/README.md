# 💬 PulseChat

**PulseChat** is a sleek, WhatsApp-inspired real-time chat web application designed with modern React and Tailwind CSS.

Developed by **Thrisa** 🚀

---

## ✨ Key Features

* **📱 Mobile & Desktop Responsive:** Adapts seamlessly to all screen sizes (includes a mobile back button `←` for easy navigation).
* **💬 Contextual Chat Experience:**
  * Displays `Online / Offline` status in the active chat header only.
  * Shows last message snippets and timestamps in the sidebar.
  * Real-time message status indicators (`✓` Sent, `✓✓` Blue Tick Delivered).
* **👤 Dynamic Local Avatars:** Custom user profile photos managed directly via `assets/images`.
* **🤖 Smart Auto-Reply:** Dynamic simulated replies based on sent messages.
* **😊 Emoji Picker:** Quick-access emoji bar for instant reactions.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite
* **Styling:** Tailwind CSS
* **Asset Utility:** Custom JavaScript loaders (`userImages.js`)
